Changes ko Live Karein

Yahan ka data abhi sirf is browser me hai. Website par laane ke liye ye 4 step:

Download Update dabao — ek pathan-steel-update.zip file milegi.

Us zip par right-click → Extract All. Andar js aur images folder honge.

Dono folder apne website folder pathan-steel-static me copy kar do — Replace pooch e to haan karo.

Website kholo → Ctrl + Shift + R. GitHub par ho to wahi dono folder upload/commit kar do.

Zip nahi kholni? Ye tareeka sabse aasan hai — products.js aur nayi photos alag-alag download hongi, seedha Downloads folder me. Fir bas do baar drag karo. Koi Extract, koi Unblock nahi.

Sirf naam / description / company badle hain aur koi nayi photo nahi daali? Tab sirf ye chhoti file kaafi hai.

Backup: zip file hi aapka poora backup hai — usko date ke saath kahin safe rakh lo (jaise update-05sep.zip). Kabhi kuch galat ho to neeche wale box se wapas la sakte ho.
