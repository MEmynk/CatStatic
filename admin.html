Changes ko Live Karein

Yahan jo bhi aapne add kiya hai wo abhi sirf is browser me save hai. Live karne ke liye ye 3 step:

Download button dabao — products.js file download hogi.

Us file ko apne website folder ke js folder me daal do (purani file replace kar do).

Website kholke Ctrl + Shift + R — sab live! GitHub par ho to bas wahi ek file upload kar do.

Backup tip: download ki hui products.js file hi aapka poora data hai — usko kahin safe rakh lena. Naya computer ho to ussi file ko js folder me daal ke admin kholna, sara data wapas aa jayega.
